# Living Norway Open Science Training — course website

Website for the Living Norway Open Science courses and workshops: course overview, teaching content links, resources, and contact.

**Site:** <https://open-science-course.github.io/course_website/>

**Teaching material:** [OS-training-material](https://github.com/Open-Science-Course/OS-training-material)

## Build

Quarto website; published HTML is in `docs/`.

```bash
quarto preview
quarto render
```
